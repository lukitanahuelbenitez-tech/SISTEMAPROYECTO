# Actividad 5 - Modelado de Datos con Struct y Punteros

## Descripción

Este proyecto corresponde a la Actividad 5 de Laboratorio de Programación (LPR).

El programa utiliza una estructura (`struct`) para agrupar diferentes datos de una entidad y utiliza punteros para acceder y modificar sus datos mediante el operador flecha (`->`).

## Funcionamiento

El programa:

- Solicita un ID.
- Solicita el nombre o descripción de una entidad.
- Solicita una métrica de operación.
- Utiliza un puntero para modificar los datos de la estructura.
- Muestra los datos registrados.
- Muestra la dirección de memoria de la estructura.

## Conceptos utilizados

- `struct`
- Punteros
- Operador flecha (`->`)
- Pasaje por dirección
- `cin.ignore()`
- `cin.getline()`
